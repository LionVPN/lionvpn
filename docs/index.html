Built to be trusted

What ships with every release.

Signed login replies

Server replies are signed and verified on UDP, TCP and CDN paths. A tampered reply is rejected.

Clean, signed builds

Release bundles are scanned for leftover development files before signing. macOS builds are notarized and stapled; Windows builds are code-signed.

Local devices keep working

Private and link-local ranges stay outside the tunnel, so AirPlay, printers and home devices behave while you are connected.
