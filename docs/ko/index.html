서명된 로그인 응답

서버 응답은 UDP, TCP, CDN 경로에서 서명되고 검증됩니다. 변조된 응답은 거부됩니다.

깨끗하고 서명된 빌드

릴리스 번들은 서명 전에 남아 있는 개발 파일을 검사합니다. macOS 빌드는 공증 및 스테이플, Windows 빌드는 코드 서명을 거칩니다.

로컬 기기는 그대로

사설 및 링크 로컬 주소 대역은 터널 밖에 두므로, 연결 중에도 AirPlay, 프린터, 가정 내 기기가 정상 작동합니다.
