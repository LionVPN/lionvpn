## 協定與傳輸

| 傳輸方式 | 說明 | 平台 |
| --- | --- | --- |
| **LionVPN UDP** | 原生 UDP 隧道，帶 KCP 可靠傳輸層，AES-256 加密與 ECC 金鑰交換 | macOS、Windows、iOS、Android、Linux |
| **LionVPN TCP** | 同一協定走 TCP，用於封鎖 UDP 的網路 | macOS、iOS、Android、Linux |
| **CDN 模式** | 標準 HTTPS 上的 VLESS + XHTTP over TLS，適合過濾嚴格的網路 | macOS 6.4、iOS |
| **Hysteria 2** | 基於 QUIC 的傳輸，適合丟包或限速的線路 | macOS 6.4、iOS（下個版本） |
| **SOCKS5** | 依部署開放 | 取決於客戶端版本與部署環境 |
| **H2** | 逐步加入中 | 路線圖 |

實際能力取決於客戶端建置與部署環境，並非每個版本都會開放所有接入模式。

## 近期更新

- **macOS 6.4** — 支援 CDN 模式與 Hysteria 2，設定中可選擇中轉線路，強化經典 UDP/TCP 通道。Apple 公證的通用二進位。
- **iOS** — 所有伺服器預設使用 CDN 模式。帶真實 DNS 走隧道的 Hysteria 2 將在下個版本提供。
- **Linux 與 OpenWrt 0.1.3-rc.1** — 首次公開發布 Debian/Ubuntu、RHEL/Fedora、可攜式套件和 OpenWrt 安裝包。
- **登入完整性** — 伺服器登入回應在 UDP、TCP 和 CDN 路徑上均帶簽章並驗證。
- **行動網路更少斷線** — 行動網路下登入重試分輪退避，不再重複登入；連線期間 AirPlay、印表機等區域網路裝置正常可用。

## 常見問題

**LionVPN 主要保護什麼？**
LionVPN 會加密你的網路流量、隱藏你的 IP 位址，並在你使用公共或共享網路時降低暴露風險。

**多久可以開始使用？**
選擇方案、下載對應裝置的應用程式、登入並連上建議節點，幾分鐘內即可開始使用。

**LionVPN 適合辦公、出行和串流嗎？**
LionVPN 適合日常瀏覽、辦公、出行和帳戶存取。對特定第三方服務的相容性不應視為保證。
