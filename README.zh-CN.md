## 关于 LionVPN

LionVPN 强调无日志、安全与隐私，保留地区服务器，并通过自动线路选择帮助用户更快选择合适节点，获得可靠、快速的连接体验。

我们的目标很直接：把无日志、隐私保护、连接安全、稳定性和速度真正做好，让日常上网、办公和出行都更安心。地区服务器当前仍然保留。SOCKS5 已支持，同时 H2 正随着当前 VPN 体验逐步加入。

## 协议与传输

| 传输方式 | 说明 | 平台 |
| --- | --- | --- |
| **LionVPN UDP** | 原生 UDP 隧道，带 KCP 可靠传输层，AES-256 加密与 ECC 密钥交换 | macOS、Windows、iOS、Android、Linux |
| **LionVPN TCP** | 同一协议走 TCP，用于封锁 UDP 的网络 | macOS、iOS、Android、Linux |
| **CDN 模式** | 标准 HTTPS 上的 VLESS + XHTTP over TLS，适合过滤严格的网络 | macOS 6.4、iOS |
| **Hysteria 2** | 基于 QUIC 的传输，适合丢包或限速的线路 | macOS 6.4、iOS（下个版本） |
| **SOCKS5** | 按部署开放 | 取决于客户端版本与部署环境 |
| **H2** | 逐步加入中 | 路线图 |

实际能力取决于客户端版本和部署环境，并非每个版本都开放所有接入模式。

## 近期更新

- **macOS 6.4** — 支持 CDN 模式与 Hysteria 2，设置中可选择中转线路，加固经典 UDP/TCP 通道。Apple 公证的通用二进制。
- **iOS** — 所有服务器默认使用 CDN 模式。带真实 DNS 走隧道的 Hysteria 2 将在下个版本提供。
- **Linux 与 OpenWrt 0.1.3-rc.1** — 首次公开发布 Debian/Ubuntu、RHEL/Fedora、便携包和 OpenWrt 安装包。
- **登录完整性** — 服务器登录回包在 UDP、TCP 和 CDN 路径上均带签名并校验。
- **移动网络更少掉线** — 蜂窝网络下登录重试分轮退避，不再重复登录；连接期间 AirPlay、打印机等局域网设备正常可用。

## 常见问题

**LionVPN 主要保护什么？**
LionVPN 加密你的网络流量、隐藏你的 IP 地址，并在你使用公共或共享网络时降低暴露风险。

**多久可以开始使用？**
选择套餐、下载对应设备的应用、登录并连接推荐节点，几分钟内即可开始使用。

**LionVPN 适合办公、出行和流媒体吗？**
LionVPN 适合日常浏览、办公、出行和账户访问。对特定第三方服务的兼容性不应视为保证。
