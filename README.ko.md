## LionVPN을 선택하는 이유

노로그가 먼저이고, 그 다음이 보안, 프라이버시, 지역별 서버, 그리고 더 빠르고 안정적인 연결을 위한 경로 선택입니다.

| | |
| --- | --- |
| 🔒 **노로그 프라이버시** | LionVPN은 노로그를 최우선으로 두어 사용자의 활동이 사용자 자신의 것으로 남도록 하며, 프라이버시를 제품 경험의 중심에 둡니다. |
| ⚡ **자동 경로 선택** | 자동 경로 선택이 더 빠르고 안정적인 서버 경로를 찾아 주어 수동 선택의 부담을 줄입니다. |
| 🌍 **지역별 서버** | 지역별 서버 위치를 유지하여 속도, 안정성, 가용성이 필요한 곳 가까이에서 연결할 수 있습니다. |
| 🛡️ **보안과 프라이버시** | 안전한 암호화 연결과 프라이버시 우선 설계로 일상적인 브라우징, 업무, 여행을 보호합니다. |
| 🔁 **안정적인 연결** | 속도, 안정성, 보안, 프라이버시가 하나의 연결 경험 안에서 함께 작동합니다. |
| 🧭 **프로토콜 로드맵** | 현재 제품은 VPN 중심입니다. SOCKS5는 활성화된 환경에서 지원되며, H2는 단계적으로 추가되고 있습니다. |

## LionVPN 소개

LionVPN은 노로그, 강력한 보안과 프라이버시, 지역별 서버, 자동 경로 선택을 강조하여 사용자가 더 빠르고 신뢰할 수 있는 연결에 도달하도록 돕습니다.

목표는 분명합니다. 프라이버시를 보호하고, 연결을 안전하게 유지하며, 복잡함 없이 빠르고 안정적인 서버에 쉽게 연결하는 것입니다. 지역별 서버는 현재도 이용할 수 있습니다. SOCKS5는 활성화된 환경에서 지원되며, H2는 현재의 VPN 경험과 함께 단계적으로 추가되고 있습니다.

## 프로토콜과 전송 방식

| 전송 방식 | 설명 | 플랫폼 |
| --- | --- | --- |
| **LionVPN UDP** | KCP 신뢰성 계층, AES-256 암호화, ECC 키 교환을 갖춘 네이티브 UDP 터널 | macOS, Windows, iOS, Android, Linux |
| **LionVPN TCP** | UDP를 차단하는 네트워크를 위한 동일 프로토콜의 TCP 버전 | macOS, iOS, Android, Linux |
| **CDN 모드** | 표준 HTTPS 위의 VLESS + XHTTP over TLS, 강하게 필터링되는 네트워크용 | macOS 6.4, iOS |
| **Hysteria 2** | 손실이 많거나 속도가 제한된 회선을 위한 QUIC 기반 전송 방식 | macOS 6.4, iOS(다음 릴리스) |
| **SOCKS5** | 활성화된 환경에서 지원 | 클라이언트 빌드와 배포 환경에 따라 다름 |
| **H2** | 단계적으로 추가 중 | 로드맵 |

사용 가능 여부는 클라이언트 빌드와 배포 환경에 따라 다릅니다. 모든 릴리스에서 모든 접속 모드가 제공되는 것은 아닙니다.

## 새로운 소식

- **macOS 6.4** — CDN 모드와 Hysteria 2 지원, 설정에서 중계 회선 선택, 기존 UDP/TCP 채널 강화. 공증된 Universal 빌드.
- **iOS** — 모든 서버에서 CDN 모드가 기본 전송 방식입니다. 터널을 통한 실제 DNS를 지원하는 Hysteria 2는 다음 릴리스에서 제공됩니다.
- **Linux 및 OpenWrt 0.1.3-rc.1** — Debian/Ubuntu, RHEL/Fedora, 포터블 아카이브, OpenWrt용 첫 공개 패키지.
- **로그인 무결성** — 서버 로그인 응답에 서명하고 UDP, TCP, CDN 경로에서 검증합니다.
- **모바일 네트워크 끊김 감소** — 셀룰러 회선에서 로그인 재시도를 백오프하고 불필요한 재로그인을 제거했습니다. 연결 중에도 AirPlay, 프린터 등 로컬 기기를 사용할 수 있습니다.
