| | |
| --- | --- |
| 🔒 **ノーログとプライバシー** | ノーログを重視し、あなたの接続アクティビティをあなたのものとして保てるよう、プライバシーを体験の中心に置いています。 |
| ⚡ **自動ルート選択** | 自動ルート選択が、より適したサーバーと経路を自動で選び、より速く安定した接続につなげます。 |
| 🌍 **地域別サーバー** | 地域別サーバーを維持し、速度や安定性が重要な場所に近いロケーションを選びやすくしています。 |

| 🔁 **信頼できる接続** | 速度、安定性、セキュリティ、プライバシーを一つの接続体験にまとめます。 |

## LionVPN について

LionVPN はノーログ、セキュリティとプライバシー、地域別サーバー、そして自動ルート選択を重視し、より速く信頼できる接続体験を目指します。

目指しているのはシンプルです。ノーログ、プライバシー保護、接続の安全性、安定性、速度を日常利用の中で実感しやすくすることです。地域別サーバーは現在も利用できます。SOCKS5 は対応済みで、H2 は現在の VPN 体験に沿って段階的に追加されています。

## プロトコルとトランスポート

| トランスポート | 説明 | プラットフォーム |
| --- | --- | --- |
| **LionVPN UDP** | KCP 信頼性レイヤー、AES-256 暗号化、ECC 鍵交換を備えたネイティブ UDP トンネル | macOS、Windows、iOS、Android、Linux |
| **LionVPN TCP** | UDP が遮断されるネットワーク向けに、同じプロトコルを TCP で利用 | macOS、iOS、Android、Linux |
| **CDN モード** | 標準 HTTPS 上の VLESS + XHTTP over TLS。強くフィルタリングされたネットワーク向け | macOS 6.4、iOS |
| **Hysteria 2** | パケットロスや帯域制限のある回線向けの QUIC ベースのトランスポート | macOS 6.4、iOS（次回リリース） |
| **SOCKS5** | 有効化されている環境で対応 | クライアントのビルドと配備環境による |
| **H2** | 段階的に追加中 | ロードマップ |

利用可能な機能はクライアントのビルドと配備環境に依存し、すべてのリリースで全アクセスモードが公開されるわけではありません。

## 最新情報

- **macOS 6.4** — CDN モードと Hysteria 2 に対応、設定で中継回線を選択可能、従来の UDP/TCP チャネルを強化。公証済み Universal ビルド。
- **iOS** — すべてのサーバーで CDN モードが既定のトランスポートに。トンネル経由の実 DNS を備えた Hysteria 2 は次回リリースで提供。
- **Linux と OpenWrt 0.1.3-rc.1** — Debian/Ubuntu、RHEL/Fedora、ポータブルアーカイブ、OpenWrt 向けの初の公開パッケージ。
- **ログインの完全性** — サーバーのログイン応答に署名を付け、UDP、TCP、CDN の各経路で検証。
- **モバイル回線での切断を削減** — セルラー回線でログイン再試行をバックオフし、不要な再ログインを解消。接続中も AirPlay やプリンターなどのローカル機器を利用可能。

## よくある質問

**LionVPN は何を保護しますか？**
LionVPN は通信を暗号化し、IP アドレスを隠し、公共または共有ネットワーク利用時の露出リスクを下げます。

**どれくらいですぐ使い始められますか？**
プランを選び、端末用アプリをダウンロードし、サインインして推奨ロケーションに接続すれば、数分で使い始められます。

**仕事、旅行、ストリーミングにも使えますか？**
LionVPN は日常のブラウジング、仕事、旅行、アカウントへのアクセスに適しています。特定のサードパーティサービスとの互換性は保証されるものではありません。
